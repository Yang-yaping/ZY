# 国密PoW课程实验

网站路径：课程作业 → 问题002 → 国密PoW测试系统。修改节点数、难度、区块数和重复次数后运行，下载本次原始JSON。也可以在项目根目录运行 `python -m mining.run_experiments` 复测批量场景，再运行 `python -m mining.analyze` 更新对应汇总。

SM3来自Python/OpenSSL，SM2/SM3来自gmssl 3.2.2。签名随机数显式用secrets产生，避免库默认普通随机数；私钥不出现在结果或浏览器中。仅课堂教学，非经过审计的生产密码实现。

固定难度12位，1/2/4/8个同机线程竞争节点，每组3块×3轮；记录逐节点哈希尝试、总工作量、墙钟时间、进程CPU秒、速率与成功状态。每次搜索有全局约12秒和每节点20万次尝试上限；未成功会如实记失败，不能把超时当成挖矿成功。整个实验耗时另含密钥生成和签名校验，逐块挖矿耗时不包含这些阶段。

results/benchmark.json是实际批量运行的公开记录，不含私钥。PoW有较大随机方差，应复测后分析，不能凭一次结果断言节点越多越快。同机线程共享CPU且受Python调度限制；这是国密比特币式测试模型，不是兼容比特币主网的实现，也没有实现完整网络传播与分叉共识。

**功率未实测。** JSON的measured_system_w与energy_j默认为null。只有外部功率计测得平均整机有功功率后，才在页面手动录入P并按E=P×挖矿秒计算阶段整机能耗；不要再乘同机节点数。CPU秒不能转换成瓦数，也不能把额定功率当实测。仪表量程、采样窗口与空闲基线应随正式实验另行记录。
